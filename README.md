# Under a Clear Sky · 晴空之下

一个网页里的滨海小镇 —— 追求新海诚式的通透蓝天、大积云、近岸 turquoise 海水,和一条"走着走着就看见海"的主街。

**在线体验**:https://zxc403.github.io/Under-a-clear-sky/

## 当前版本:氛围原型 α(v0.1)

- 主街 400m + 海滨广场 + 近岸水面(灰盒体量,正式建筑后续逐栋替换为手搓模型)
- 时间锁定 14:28 午后
- 程序化天空:大气渐变 + 大积云(前向散射银边)+ 卷云 + 太阳光晕
- 程序化海面:近岸 turquoise 渐变 + 菲涅尔天空反射 + 太阳碎金 + 岸线泡沫
- 治愈调色:高明度、阴影偏青、暖高光、轻暗角 + Bloom
- 天空 / 水面 / 雾共享同一组颜色函数,水天一色

## 操作

| 平台 | 移动 | 视角 | 其他 |
| --- | --- | --- | --- |
| 手机(横屏) | 左半屏摇杆 | 右半屏单指滑动 | 右下:跳跃 / 冲刺 / 交互 |
| 电脑 | WASD / 方向键 | 鼠标(点击锁定) | Shift 冲刺 · 空格跳跃 · E 交互 |
| 手柄 | 左摇杆 | 右摇杆 | A 跳跃 · X 交互 · RB/RT 冲刺 |

## 技术

- Three.js `WebGPURenderer`:WebGPU 优先,不支持时自动降级 WebGL2
- 全部着色器用 TSL 编写,一套代码编译到 WGSL / GLSL 双后端
- Vite 构建,零外部素材(天空、云、海、棕榈全部程序化生成)

## 本地开发

```bash
npm install
npm run dev      # 本地预览
npm run build    # 产物在 dist/
```
